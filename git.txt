Features of Git:

Git is a distributed version control system used to manage and track changes in software projects.

Version Control – Keeps track of changes made to files.

Distributed System – Every developer can have a complete copy of the project and its history.

Fast – Most Git operations are performed locally, so they are quick.

Branching – Allows developers to create separate branches for developing new features.

Merging – Combines changes from different branches into one branch.

Backup & Recovery – Previous versions can be recovered if something goes wrong.

Collaboration – Multiple developers can work on the same project.

Track Changes – Shows what was added, modified, or deleted.

Commit History – Maintains a history of saved changes with commit messages.

Works with Remote Repositories – Can connect to platforms such as GitHub and GitLab.
